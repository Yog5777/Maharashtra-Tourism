# 🏛️ Maharashtra Tourism Website

A modern, responsive frontend web project designed to showcase the rich culture, heritage, and tourist destinations of Maharashtra. This project modernizes legacy table-based designs into a clean, cohesive, and green-themed UI design system.

## ✨ Key Features
* **Cohesive Design System:** A standardized green-themed layout featuring a global header and a responsive navigational sub-header.
* **District & Site Pages:** Includes dedicated pages for major districts and tourist spots (e.g., Akola, Nagpur, Narnala Fort, Raj Rajeshwar Temple, Nehru Park, Ambazari Lake, etc.).
* **Responsive Architecture:** Built using modern CSS Flexbox and Grid to ensure seamless viewing across mobile, tablet, and desktop devices.
* **Interactive UI Elements:** Clean card layouts, styled lists, and embedded Google Maps for easy location tracking.

---

## 🛠️ Tech Stack
* **HTML5** (Semantic Markup)
* **CSS3** (Flexbox, Grid, Custom Properties/Variables)
* **FontAwesome 6.5.1** (For icons)
